# Security policy

Security fixes are supported for the latest stable release. Upgrade to the
latest stable release before checking whether an issue is still present.

Report suspected vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/syz51/go-mod.nvim/security/advisories/new).
Include the affected version, reproduction steps, and potential impact. Remove
credentials and other private information from any attached logs or examples.
Please avoid public issues or discussions for undisclosed vulnerabilities.
